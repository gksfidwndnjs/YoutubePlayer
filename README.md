# Metalwave for YouTube
### (YouTube Music Player)

화면 구석에 도킹되는 **컴팩트 음악 플레이어 위젯**
YouTube 음원 · 내 PC 폴더 · 동기화 가사 — 브러시드 메탈 + CRT 그린 레트로 UI · Windows · Electron

## 소개

Metalwave for YouTube는 작업 중에 한쪽 구석에 띄워두고 쓰는 작은 데스크톱 음악 플레이어입니다.
브라우저 탭을 따로 열지 않고도 YouTube 음원을 검색·재생·다운로드할 수 있고,
내 PC에 있는 음악 폴더도 재생목록으로 만들어 그대로 재생합니다.
평소엔 플레이어 바만 보이다가 토글하면 재생목록이 제자리에서 부드럽게 펼쳐집니다.

전체 UI는 브러시드 스테인리스 메탈 베젤과 CRT 그린 화면 톤으로 꾸며진 레트로 미니 기기 컨셉입니다.

## 주요 기능

### 재생

- YouTube 음원 스트리밍 재생 (`yt-dlp` 기반)
- 다운로드된 트랙은 **로컬 파일 우선 재생**, 없으면 스트리밍 폴백
- 재생 모드: **한 번만 / 전체 반복 / 한 곡 반복**
- 자동 다음 곡, 볼륨·음소거, 진행바 시크, 회전하는 디스크 애니메이션
- 앱을 껐다 켜도 **마지막에 듣던 곡과 재생 위치가 복원**됩니다 (일시정지 상태로)
- 키보드 단축키

  | 키 | 동작 |
  |----|------|
  | `Space` | 재생 / 일시정지 |
  | `→` 또는 `n` | 다음 곡 |
  | `←` 또는 `p` | 이전 곡 |

### 가사

- [LRCLIB](https://lrclib.net/)에서 **시간 동기화 가사**를 자동으로 찾아옵니다 (별도 키 불필요)
- 곡 정보 ↔ 가사 화면을 ♪ 버튼으로 전환. 재생에 맞춰 현재 줄이 위로 밀려 올라갑니다
- 지저분한 YouTube 제목(`Artist - Song (Official Video) [4K]`)에서 아티스트·곡명을 추려 검색하며,
  동기화 가사가 없는 곡은 버튼이 ✕로 비활성화됩니다

### 재생목록

- 접이식 재생목록(큐) 패널 · 트랙 추가/삭제/순서 유지
- **YouTube 재생목록 URL**로 플레이리스트 추가, 여러 목록 간 전환
- **Google 로그인** — 내 YouTube 재생목록(좋아요 포함, 비공개 목록도)을 전부 불러옵니다
- **내 폴더 추가** — PC의 음악 폴더를 그대로 재생목록으로 (아래 참고)
- 재생목록 팝업: 이름 검색, 트랙 수 배지, 전체 갱신, 목록별 삭제
- **자동 갱신** — 앱을 켤 때 연결된 목록을 원본과 대조해 삭제된 곡은 빼고 새 곡은 추가합니다.
  기존 순서와 직접 추가한 곡은 유지되며, 원본 링크가 없어 갱신할 수 없는 목록은 ⚠로 표시됩니다
- 곡·재생목록 검색 (YouTube Data API v3 키 필요) — 검색 결과 상단에 **공식 음원**을 따로 추려 보여주고,
  재생목록 결과는 열어서 곡 단위로 큐에 담을 수 있습니다

### 내 폴더 (로컬 음악)

- 재생목록 팝업의 **`＋ 폴더`** 버튼으로 폴더를 고르면 하위 4단계까지의 음악 파일
  (`mp3` `m4a` `flac` `opus` `wav` `ogg` `aac` `wma` 등)을 담은 재생목록이 만들어집니다
- **인터넷·API 키·로그인 없이** 파일을 그대로 재생합니다
- 곡 정보는 파일명에서 읽습니다
  - `제목 [영상ID].m4a` (이 앱이 받은 파일) → YouTube 썸네일이 그대로 붙습니다
  - `07 IU - 밤편지.flac`, `1-18. Artist - Title.mp3` → 트랙 번호를 떼고 아티스트/제목으로 분리
  - 이렇게 추린 정보로 가사 검색도 동작합니다
- 앨범 아트는 파일에 내장돼 있으면 표시합니다. 화면에 보이는 줄만 꺼내오고, 아트가 없는 파일은
  기록해 두므로 곡이 수백 개여도 목록이 느려지지 않습니다
- 폴더에 파일을 넣거나 빼면 다음에 목록을 열 때 자동 반영됩니다 (디스크 순서 = 재생 순서)
- 목록에서 제거해도 **폴더와 파일은 삭제되지 않습니다**

### 다운로드

- 트랙 개별 다운로드 + 큐 전체 **일괄 다운로드** (진행/완료 상태 표시)
- `m4a` + 썸네일 임베드로 저장, 재생목록 이름의 하위 폴더로 정리
- 실패 시 **자동 재시도**(2.5초 → 5초). 삭제·비공개·연령/지역 제한처럼 재시도가 무의미한 실패는 즉시 건너뜁니다
- 실패 원인을 그대로 표시하고 `download-errors.log`에 기록 (설정 → 다운로드 → 로그 열기)
- 다운로드 폴더 지정 가능(기본 `음악\YTmusic`). 폴더를 바꾸면 **기존 파일을 새 폴더로 옮길지** 물어봅니다
- 음악 폴더가 OneDrive의 클라우드 전용 파일이면 한 번 경고합니다

### 창 · 멀티모니터

- **버튼 기반 창 배치** — 위치 버튼(2×2 그리드)으로 코너 스냅 + 모니터 전환
  (네이티브 드래그가 멀티모니터에서 순간이동하는 문제를 대체)
- 상단 코너에 배치하면 레이아웃이 뒤집혀 재생목록이 아래로 펼쳐집니다
- 보조 모니터에서 **사라짐/순간이동 없음** (투명창 `setShape` 제거 — [조사 기록](docs/multimonitor-shape-issue.md))
- 모니터 높이에 맞춘 일관 스케일링, 위젯 바깥 투명 영역은 클릭이 통과됩니다
- 항상 위(always-on-top) 토글, 최소화/닫기, 프레임리스 투명창

### 설정 · 업데이트

- 설정(⚙): API 키, Google 로그인, 음질(Best / Standard ≤128 kbps), 자동 다음 곡,
  음악 폴더, 글꼴 5종·글꼴 크기 4단계, CRT 글로우 효과
- 첫 실행 시 음악 저장 폴더를 먼저 물어봅니다
- **자동 업데이트** — 새 버전이 있으면 알려주고, 동의하면 내려받아 재시작 시 적용합니다
  (진행률은 앱 안과 작업 표시줄에 함께 표시)
- 앱을 켤 때 **yt-dlp를 자동 갱신**합니다. YouTube 변경으로 다운로드가 깨지는 것을 막기 위한 것으로,
  실패해도 앱 사용에는 지장이 없습니다

## API 키 없이 되는 것 / 안 되는 것

**YouTube Data API v3 키가 필요한 기능은 검색 하나뿐입니다.** 키 없이도 나머지는 전부 동작합니다.

| 기능 | API 키 필요 | 비고 |
|------|:---:|------|
| 곡·재생목록 **검색** | **필요** | 키가 없으면 검색창에 "Set an API key in Settings" 안내가 뜹니다 |
| URL로 영상/재생목록 추가 | 불필요 | yt-dlp가 처리 |
| 재생 · 다운로드 | 불필요 | yt-dlp |
| Google 로그인으로 내 재생목록 불러오기 | 불필요 | 로그인 토큰(OAuth)으로 조회 |
| 재생목록 자동/전체 갱신 | 불필요 | yt-dlp 또는 로그인 토큰 |
| 내 폴더(로컬 음악) 재생 | 불필요 | 완전 오프라인 |
| 가사 | 불필요 | LRCLIB |

즉 **Google 로그인만 해두면** 내 재생목록을 불러와 재생·다운로드하는 것까지 전부 됩니다.
키를 넣지 않으면 앱 안에서 새 곡을 **검색**할 수 없을 뿐이고, 이때는 YouTube에서 URL을 복사해
"Add by URL"로 넣으면 같은 결과를 얻을 수 있습니다.

헤더의 점 표시기로 키 상태를 확인할 수 있습니다 (회색 = 없음 / 초록 = 설정됨).

## 설치

[**Releases**](https://github.com/gksfidwndnjs/YoutubePlayer/releases/latest)의 **Assets**에서
버전 번호가 붙은 **`Metalwave-Setup-1.4.10.exe`** 같은 파일을 받아 실행하세요.
(함께 올라온 `latest.yml`과 `.blockmap`은 앱의 자동 업데이트가 쓰는 파일이라 받지 않아도 됩니다.)

설치 과정은 세 단계입니다.

1. **설치 위치 선택** — 기본값은 현재 사용자 계정 폴더라 관리자 권한이 필요 없습니다.
   "모든 사용자용"을 고르면 UAC 창이 뜹니다.
2. **바로가기 선택** — 바탕화면 바로가기를 만들지 고를 수 있습니다(기본 켜짐).
   시작 메뉴 바로가기는 항상 `Metalwave for YouTube` 이름으로 생성됩니다.
3. 설치 후 첫 실행 때 **음악 저장 폴더**를 물어봅니다.

한 번 설치하면 이후 새 버전은 **앱이 알아서 알려주고 업데이트**합니다.
업데이트 설치는 조용히 진행되며 기존 바로가기를 그대로 둡니다.

제거는 Windows **설정 → 앱**에서 하면 되고, 바탕화면 바로가기도 함께 지워집니다.
받아둔 음악 파일과 설정은 남습니다.

> ⚠️ 코드 서명 인증서가 없어 설치할 때 Windows SmartScreen 경고가 뜹니다.
> **추가 정보 → 실행**으로 진행하면 됩니다.

## 사용법

1. 앱을 실행하면 주 모니터 **우하단**에 위젯이 나타납니다.
2. 곡을 넣는 방법은 세 가지입니다.
   - 🔍 버튼 → **Add by URL**에 영상/재생목록 URL 붙여넣기
   - 🔍 버튼 → **검색** (API 키 필요)
   - 재생목록 버튼 → **`＋ 폴더`** 로 내 PC 폴더 추가
3. 설정(⚙)에서 **Google 로그인**을 하면 내 YouTube 재생목록이 전부 들어옵니다.
4. 위치 버튼으로 원하는 모니터·코너에 배치하세요.

## Google 로그인

설정(⚙)에서 **Google로 로그인**을 누르면 본인의 YouTube 재생목록(좋아요 포함)을 앱으로 불러옵니다.
**API 키 입력 같은 별도 설정은 필요 없습니다.**

1. 버튼을 누르면 브라우저에 Google 로그인 창이 열립니다.
2. 처음에는 **"Google에서 확인하지 않은 앱"** 경고가 보일 수 있습니다 →
   **고급 → "Metalwave for YouTube(으)로 이동" → 허용**.
   (Google 검증을 받지 않은 앱이라 표시되는 정상적인 안내입니다.)
3. 동의하면 재생목록이 **로컬 / 내 폴더 / Google 계정** 카테고리로 나뉘어 나타납니다.

- 앱은 **읽기 전용**(`youtube.readonly`) 권한만 사용합니다.
- 인증 토큰은 **사용자 PC에만 저장**되며 외부 서버로 전송되지 않습니다 —
  [개인정보처리방침](https://gksfidwndnjs.github.io/privacy.html)
- 로그아웃은 설정에서, 권한 철회는
  [Google 계정 권한 페이지](https://myaccount.google.com/permissions)에서 가능합니다.
- OAuth 동의 화면이 **테스트 모드**인 동안에는 Google 정책상 로그인이 약 7일 후 만료됩니다.
  이때는 설정에서 다시 로그인하면 되며, 앱이 만료를 감지해 한 번만 알려줍니다.

## 저장되는 파일

앱 데이터는 `%APPDATA%\youtube-player\` 에 있습니다.

| 파일 | 내용 |
|------|------|
| `settings.json` | 설정, 마지막 재생 위치 |
| `playlists.json` | 재생목록 (폴더 재생목록은 경로와 트랙 목록) |
| `google-token.json` | Google 로그인 토큰 (로그아웃 시 삭제) |
| `download-errors.log` | 다운로드 실패 기록 |
| `covers/` | 로컬 파일에서 추출한 앨범 아트 캐시 |

음원 파일 자체는 설정에서 지정한 음악 폴더(기본 `음악\YTmusic`)에 저장됩니다.

## 기술 스택

- **Electron 35** (Chromium 134) — 프레임리스 투명 위젯 창
- **yt-dlp** (`youtube-dl-exec`) — 음원 추출/다운로드, 실행 시 자동 갱신
- **ffmpeg-static** — 썸네일 임베드, 로컬 파일 앨범 아트 추출
- **electron-updater** — GitHub 릴리스 기반 자동 업데이트
- 렌더러: 바닐라 JS + CSS (프레임워크 없음)
- 패키징: **electron-builder** (NSIS 설치 프로그램)

## 프로젝트 구조

```
src/
  main.js              메인 프로세스 (창/스케일/배치, IPC, 다운로드, yt-dlp,
                       폴더 스캔·앨범 아트, Data API, 자동 업데이트)
  oauth.js             Google OAuth 2.0 (loopback + PKCE)
  google-config.js     OAuth 자격증명 (gitignored, 빌드 시 주입)
  renderer/
    index.html         위젯 UI
    app.js             재생/큐/가사/검색/다운로드/창 배치/재생목록 로직
    style.css          메탈 + CRT 레트로 테마
    texture.js         metal.png 브러시드 텍스처 · 글꼴 설정 적용
    popups/            메뉴 · 설정 · 재생목록 팝업
assets/                아이콘, 메탈 텍스처, 미리보기 이미지
docs/                  주요 버그 조사 기록
CHANGELOG.md           버전별 변경 내역
```

## 개발

```bash
npm install
npm start          # 개발 실행
npm run build      # dist\Metalwave-Setup-x.y.z.exe 생성
```

Google 로그인 기능을 쓰려면 `src/google-config.js`가 필요합니다
(`google-config.example.js` 참고, 저장소에는 포함되지 않습니다).
