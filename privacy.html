개인정보처리방침

최종 업데이트: 2026년 6월 16일

YouTube Player(이하 "본 앱")는 사용자의 개인정보를 존중합니다. 본 방침은 본 앱이 어떤 데이터에 접근하고 어떻게 처리하는지 설명합니다. 본 앱은 사용자 본인의 기기에서만 동작하는 데스크톱 애플리케이션이며, 개발자가 운영하는 서버가 없습니다.

1. 접근하는 데이터

사용자가 Google 계정으로 로그인하면, 본 앱은 YouTube Data API v3의 읽기 전용 권한(youtube.readonly)을 사용하여 다음 정보에 접근합니다.

  • 사용자의 YouTube 재생목록 및 그 안의 동영상 항목
  • 사용자의 "좋아요 표시한 동영상" 목록
  • 재생목록 표시에 필요한 기본 채널 정보(채널명 등)

2. 데이터 이용 목적

접근한 데이터는 오직 사용자 본인의 화면에 재생목록을 표시하고 재생하기 위한 용도로만 사용됩니다. 그 외의 목적(분석, 광고, 프로파일링 등)으로는 일절 사용하지 않습니다.

3. 데이터 저장 및 전송

  • 로그인 인증 토큰(OAuth 토큰)은 사용자 기기 내부(애플리케이션 사용자 데이터 폴더)에만 저장됩니다.
  • 재생목록 데이터는 메모리에서만 처리되며 영구 저장되지 않습니다.
  • 본 앱은 사용자의 어떤 데이터도 개발자 또는 제3자의 서버로 전송하지 않습니다. 모든 API 호출은 사용자의 기기에서 Google 서버로 직접 이루어집니다.

4. 데이터 공유

본 앱은 사용자 데이터를 누구와도 공유, 판매, 양도하지 않습니다.

5. Google API 사용에 대한 고지

본 앱의 Google 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 준수합니다.

6. 권한 철회

사용자는 언제든지 앱 내 로그아웃 또는 Google 계정 권한 페이지에서 본 앱의 접근 권한을 철회할 수 있습니다. 로그아웃 시 기기에 저장된 토큰은 삭제됩니다.
